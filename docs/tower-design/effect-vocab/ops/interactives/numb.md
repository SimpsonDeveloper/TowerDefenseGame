# Op: Numb

**Kind:** passive cross-scale (reads R)
**Reacts to:** R (illusion resistance)

---

## Definition

Numb makes an enemy's **Freeze threshold scale with its R** — the lower the R, the less
Chill it takes to Freeze. A mind-broken enemy has no will to resist the cold, so a
**mind-damage** build silently makes a **Freeze** build cheaper. Two towers built for
unrelated reasons quietly multiply. The R → threshold-reduction curve is an open knob.

## Interactive

Passes the interactive test (canonical definition:
`../../vocab-overview/overview.md` → *The interactive test*).

- Remove **mind-damage** (R stays full) → threshold unchanged; Numb does nothing.
- Remove the **Chill/Freeze** path → no threshold to cheapen.
- Together: draining R only matters because Numb turns it into a colder enemy, and Chill
  freezes sooner only because Numb read the drained R ⇒ interactive.

## Open knobs
- R → threshold-reduction curve · floor (how cheap Freeze can get at R = 0).
