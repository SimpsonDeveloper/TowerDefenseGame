# Op: Numb

**Kind:** passive cross-scale (reads Mind)
**Reacts to:** Mind (illusion resistance)

---

## Definition

Numb makes an enemy's **Freeze threshold scale with its Mind** — the lower the Mind, the less
Chill it takes to Freeze. A mind-broken enemy has no will to resist the cold, so a
**mind-damage** build silently makes a **Freeze** build cheaper. Two towers built for
unrelated reasons quietly multiply. The Mind → threshold-reduction curve is an open knob.

## Interactive

Passes the interactive test (canonical definition:
`../../vocab-overview/overview.md` → *The interactive test*).

- Remove **mind-damage** (Mind stays full) → threshold unchanged; Numb does nothing.
- Remove the **Chill/Freeze** path → no threshold to cheapen.
- Together: draining Mind only matters because Numb turns it into a colder enemy, and Chill
  freezes sooner only because Numb read the drained Mind ⇒ interactive.

## Open knobs
- Mind → threshold-reduction curve · floor (how cheap Freeze can get at Mind = 0).
