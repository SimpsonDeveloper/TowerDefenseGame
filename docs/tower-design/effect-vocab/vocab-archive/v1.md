# Crystal Tower — Effect Vocabulary v1 (archived)

Frozen snapshot of the first concrete pass at the authored effect vocabulary:
states, triads, and crystal groundings. Self-contained. Kept for history —
active work continues in a later version.

Core principle:
**You author a finite vocabulary of triads + typed interaction rules; the player's
reachable build-space is the emergence.** Emergence lives in the *sentences*
(builds), never in new *words* (statuses). No producing undefined statuses.

A **triad** = `producer → detectable state → consumer`, where the consumer is
*interactive* (non-additive). Test: remove one part — does the other's behavior
change? No → additive (reject). Yes → interactive (keep).

## Triads (states)

| State (detectable) | Ladder? | Producer | Consumer (interactive payoff) | Why not additive |
|---|---|---|---|---|
| Chill → Freeze | yes (slow→stop) | sapphire chill, stacks past threshold | **Shatter**: consume Freeze → burst scaling with chill stacks | spends the status |
| Burn | yes (smolder→blaze) | rate × power ignition | **Flareup**: consume burn stacks → instant detonation | converts DoT-future into now-damage |
| Corrode | ramps | acid ops | **Dissolve**: consume corrode → execute chunk / convert to Brittle | nonlinear w/ stack count |
| Brittle | flat | brittle ops, or shatter aftermath | **Shatter** (shared input) | currency Shatter spends |
| Mark / Sigil | flat | sigil op | **Detonate / focus**: arc prioritizes Marked, bonus hits | retargets routing |
| Clustered | density | **Lure** pulls enemies together | **Nova/Splash** bonus vs density | positioning gates payoff |
| Mired | flat | mire (anchor in zone) | **Field** DoT ticks full duration | dwell-time, not flat damage |
| Scrambled | flat | scramble op | enables ops that only land on shielded-down foes | gate, not addition |
| Hexed | timer | hex op | enemy **death** triggers it; arc chains on death | death event → bounded cascade |

Reusable shape: **charge-and-spend** — a ladder producer (Chill/Burn/Corrode)
paired with a consume-the-stack verb (Shatter/Flareup/Dissolve). Flat states are
*enablers* (gate other effects), not charge-and-spend.

Consumers/producers are **many-to-many** (keeps authored count low):
Shatter consumes Freeze *and* Brittle; Nova consumes Clustered; Death consumes Hex.

## Crystal grounding (stat-op + element)

Each crystal does double duty: a stat facet (mechanical) and an element (flavor /
state source).

| Crystal | Stat facet | Element | Natively produces | In combo produces |
|---|---|---|---|---|
| Ruby | power | Fire | ignition seed | Burn (× emerald rate), Flareup |
| Sapphire | slow | Ice | Chill → Freeze (ladder) | Frostburn (× ruby) |
| Emerald | rate | Nature/Acid | Corrode (rate = ticks eating) | Siphon, sustains any DoT |
| Citrine | speed/range | Lightning | Arc, Scramble (EMP) | Overcharge, reach |
| Amethyst | pierce | Arcane | Hex, Mark (penetrate defense) | Field, curse effects |
| Quartz | wire/identity | Pure/catalyst | Shatter, Purify | consumes any state (× sapphire = shatter) |

Strained mappings flagged: **emerald→acid** and **amethyst→arcane** are weak
("rate = acid", "pierce = curse" aren't intuitive). Fire/Ice/Lightning/Pure read fine.

## Known gaps at v1

- **Force / gravity family** (Mire, Lure, Repel, Clustered) — no crystal source.
- **Illusion** (Mirage, Decoy) — ill-defined; rejected. No consumer reads it → no
  triad. Sat outside the system.

### Illusion resistance (the mechanic)

The maze is **psychological, not physical**. Enemies follow the player's set path
because they are fooled into thinking it is the only route.

- **R = illusion resistance** = a second health bar ("mind shield"), per enemy,
  set at spawn.
- Enemies **roll for deviation at set intervals**. Per-roll deviation chance is a
  function of current **R** (higher R → higher chance to break free).
- More time alive = more rolls = higher cumulative chance to deviate.
- **Frozen / inactive enemies skip rolls** (not attempting actions → no deviation).
- A deviating enemy leaves the path and shortcuts toward the target (skips the
  tower gauntlet → partial/full leak).
- **Illusion ops deal mind-damage to R. The break is permanent** — drive R to 0 and
  that enemy can never deviate again.

Design properties:
- **Two timers race:** kill-speed vs deviation-risk. Fast kills make illusion moot;
  tanky/long fights make it essential. Illusion is *inversely coupled to DPS*.
- **Placement role:** permanent break ⇒ apply illusion **early** (entrance gatekeeper).
  Damage lives mid/late.
- **Anti-turtle, for free:** an enemy you can't kill eventually rolls a deviation
  and leaks. No infinite-CC cheese.
- **Map is the dial:** long maze → deviation skips a lot → illusion critical;
  short path → illusion near-worthless.
- Chill is currently **risk-neutral** (no damage tradeoff yet ⇒ same lifespan ⇒
  same roll count). Only matters for leak-bound enemies, not damage-bound ones.

### Mind-damage type rule (compilation)

Type is a **routing tag on one power magnitude**, not a separate stat channel.

- `power` = magnitude. `type ∈ {kinetic, ice, mind, ...}` = which bar it deposits into.
- `kinetic` / `ice` → HP. `mind` → R.
- Stat crystals (ruby power×, emerald rate×) scale the magnitude **regardless of type**.
- Amethyst sets `type → mind`, rerouting that power to R.
- Example: `ruby → amethyst` — ruby scales power to 50, amethyst tags it mind →
  50 mind-damage to R.
- **Type is single-valued per stream.** A shot hits HP *or* R, not both.

#### Hitting both bars at once

Allowed, but not free. Two conservation-safe ways:

1. **Split the lattice (decided default).** ▲ split → two branches; tag one `mind`,
   leave one `kinetic`. Power **divides** across them, so both bars get hit, each
   weaker. The **split ratio** is the build lever (e.g. 90/10 finisher that chips R;
   20/80 controller with light damage).
2. **Hybrid crystal (one cell) — kept, deferred.** A compound that internally
   splits its one stream (e.g. 60% HP / 40% R) and deposits each part to its bar.
   Same total power, ratio baked in; trades crafting material for lattice space.

**Forbidden:** one *undivided* 50-power shot depositing 50 to HP **and** 50 to R.
That is 100 output from 50 power = conservation break = free double damage.
